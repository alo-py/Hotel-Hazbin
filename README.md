# 🏨 Hotel Booking Web Platform (Frontend) - UI/UX Case

Plataforma web responsiva diseñada para la visualización de servicios hoteleros y la gestión intuitiva de reservaciones. El objetivo principal de este proyecto fue optimizar la arquitectura de información para transformar un proceso de registro complejo en una experiencia de usuario fluida, limpia y libre de fricciones.

## 🎯 Decisiones Clave de Diseño (UX)

* **Arquitectura de Información Eficiente:** Se organizaron los servicios del hotel de forma modular mediante tarjetas (*cards*) visuales, permitiendo al usuario escanear los precios, amenidades y disponibilidad en segundos sin saturación visual.
* **Flujo de Conversión Optimizado:** El formulario de reservas fue diseñado con pasos lógicos y campos claros, reduciendo el esfuerzo del usuario (*user effort*) y previniendo el abandono a mitad del proceso.
* **Diseño 100% Responsivo:** Maquetación adaptativa que redistribuye los elementos estratégicamente al pasar de monitor a celular, asegurando que las acciones de reserva sigan siendo el punto focal (*Call to Action*) accesible en cualquier resolución.
* **Estética y Consistencia Visual:** Uso de una paleta de colores coherente y contrastes tipográficos elevados (HTML5/CSS3 nativo) para transmitir una sensación de confianza, profesionalismo y confort desde el primer contacto.

## 🛠️ Tecnologías Utilizadas

* **Desarrollo Frontend:** HTML5, CSS3 (Flexbox/Grid para layouts responsivos), JavaScript (Interactividad en el flujo).
* **Diseño y Maquetación:** Figma (Estructura de Wireframes).
